아직 계정이 없나요? 위 탭에서 일반회원 가입을 신청하세요.
아직 관리자 계정이 없나요? 회사명과 팀 정보를 입력해 관리자 계정을 바로 만들 수 있습니다.
일반회원 가입 신청 가입 신청 후 ADMIN이 회사·부서·팀 정보를 확인합니다. 승인 전에는 회사 자료에 접근할 수 없습니다.
가입 후 순서1. 신청 접수 → 2. 관리자 확인 → 3. 승인 완료 → 4. 같은 아이디/비밀번호로 로그인
관리자 가입 회사명과 팀 정보를 등록하면 관리자 계정이 바로 생성됩니다. 일반사용자 가입만 관리자 승인을 거칩니다.

Hub 웹사이트는 회사 계정과 권한을 기준으로 접근합니다. 비밀번호는 BCrypt 해시로 저장되며, 승인 전 계정은 조직 자료에 접근할 수 없습니다.
